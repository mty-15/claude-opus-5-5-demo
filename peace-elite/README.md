# 和平精英 · 海岛行动

与 `pelican-bike`、`cf-transport-ship`、`qq-speed` 并列的独立 Three.js 网页游戏。
这是**原创程序化海岛、离线单机战术竞技致敬作品**，不是官方游戏或官方海岛的等比例复刻，不包含官方模型、图片、音频、商标图形或联网服务。

## 本地构建与运行

与其他三个游戏采用相同方式：使用 esbuild 将源码、样式和 Three.js 内联成单个 HTML，**不需要开发服务器**。构建工具要求 Node.js 18 或更新版本；浏览器需要 WebGL2，推荐 Chrome / Edge。

```sh
cd peace-elite
npm install
node build.mjs
```

然后直接用浏览器打开 **`dist/index.html`**，也可将该文件放到任意静态托管服务。不要直接打开 `src/index.html`，它是用于注入代码和样式的源码模板。

构建产物不依赖 `/src` 路由、import map、外部 CDN 或后端；首次开始游戏时按浏览器规则启用声音与鼠标锁定。`dist/` 与其他项目一样不提交到 Git。
## 玩法

- **48 人单人生存赛**：1 名玩家与 47 名本地机器人。运输机进场，主动离机／到航线末端自动跳伞，自由落体、主动／低空自动开伞，落地开始搜装。
- **1.4 × 1.4 km 地图范围**：9 个原创地点，中央集镇、海岸与港区、农田、仓库、树林、山地、道路、双桥河道；31 栋可进入建筑，门洞、屋顶与地形参与碰撞和射线遮挡。
- **真实资源状态**：地图 138 个物资生成点（其中 93 个室内），按种类生成枪械、弹药与装备；机器人也需要实际搜集武器，不会凭空得到满装装备。
- **四种枪械**：M416、AKM、UMP45、Kar98k；双武器位、相应口径弹药、换弹时间、散布与后坐、瞄准和狙击放大、头部／身体伤害、头盔／防弹衣减伤。UMP45 在本作使用简化的 9mm 弹药配置，并非官方参数表。
- **医疗与战术**：急救包、持续恢复的能量饮料、可反弹且有遮挡判定的破片手榴弹、蹲伏、趴下、侧身和第一／第三人称切换。
- **转移与决胜**：五辆越野车，油门、倒车、转向与刹车；七阶段、约 10 分钟的收圈，圈外持续失去生命，最后一名存活者获胜。死亡不复活，结束后可以重新开局。
- **完整界面**：主菜单、实时罗盘／小地图、全屏战术地图、背包、键位帮助、暂停、击杀播报、胜败与排名结算；手机屏幕提供移动、视角拖动及主要操作按钮。
- **角色与程序化表现**：角色使用依法获得的 CC0 连续蒙皮基础体与动作，附原创简化战术装备；降落伞、枪械、载具和地形仍由代码生成，枪声、脚步、换弹、命中、引擎、风声和提示音仍为程序合成。

### 连续蒙皮人物接入（2026-10-29）

用户认可独立预览右侧造型后，玩家、47 名敌人和菜单展示统一采用 Quaternius CC0 基础体：65 根骨骼、三个蒙皮网格，附原创简化战术装备。肩、肘、膝、手指随真实权重变形，不再用刚性方块搭人体；第一人称枪械、战斗射线、碰撞高度、移动与拾取规则不变。此基础体和表面服装遮罩不是官方人物或专业服装成品。

构建时验证源资产哈希并重定向必要动作，另烘焙俯卧、抬头和完整装备接地轨道；游戏不携带整套原始动画库、不导入水平 root motion、不改变骨长。每页只加载一次造型资源，48 个角色共用不可变几何、材质、贴图和动作，分别拥有骨骼、mixer 与骨纹理；切局只释放旧实例，不能误释放共享贴图。远处 NPC 保留原显示距离，并降低动作采样频率。

低姿态向地面瞄准时，第三人称枪按真实几何轮廓夹限绘制角度，摄像机与伤害射线仍使用原瞄准输入，两者在极端角度可能不完全一致。站/蹲/趴/空降/死亡等跨类别过渡的约 0.20 秒内，独立视觉层按最终蒙皮及装备校正接地；稳定走跑不做完整顶点扫描，暂停或重复采样复用校正。过渡仍可能有短时 CPU 峰值；距离内的视锥外蒙皮角色仍可能提交，动画采样节流不等于跳过每帧 IK/矩阵计算。

- `npm test`：原有 94 项（含独立预览保留的旧模型 22 项）加新人物 38 项，共 132 项通过；新测试覆盖真实顶点变形、五种武器状态、接地/朝向、骨长、共享与独立资源、三次 48 角色创建/释放及缓存重建。新增接地边界覆盖 180 个低姿态/俯仰/武器组合共 2160 次采样，以及 1100 个有向姿态切换共 12100 个逐帧样本；最低点分别为 −0.0313 m 和 −0.0434 m，满足原 −0.06 m 容差。它不是所有插值时刻、同时极限俯仰和远距离节流组合的证明。
- `npm run check`：17 个 JS 文件通过；离线单 HTML 构建约 11.9 MiB，人体、所用贴图、烘焙轨道及 CC0/MIT 许可随文件内嵌，无外部 CDN 或模型请求。
- 真实 Chrome 触屏模拟：菜单与 native 开始行动后 48 个角色均为新工厂；受控玩家/敌人场景中的跑、蹲、趴、空降、降落伞、死亡、四枪、第一人称和 Kar98k 狙击正常；568×320、667×375、844×390、1024×768 下人物正常显示。重开释放已实际分配的旧骨纹理，共享贴图保留，未捕获页面异常或远程请求。
- 最终受控两角色流畅画质场景（保留普通散落物）：平视 M416/AKM 人物各 15 个可见网格、约 1.87 万三角形；全场 656 次绘制、246400 个三角形、DPR 1。下视 Kar98k 人物各 16 个网格、19290 个三角形。不同场景摆放会改变全场计数；这些是软件渲染浏览器计数，不是手机 FPS 或 48 人同屏性能保证。

独立造型预览仍保留在 `character-preview/`；游戏仅需打开构建后的 `dist/index.html`。此验收不覆盖完整十分钟对局和手机持续帧率、发热、所有服装细节。本次接入尚未部署。

### 战利品盒（2026-10-29）

敌人被淘汰后在其所在位置的可站立表面留下一个木箱，不再将身上物资全部散落。盒子保存敌人实际携带的枪械及弹匣余量、备用弹药、医疗包、能量饮料、手雷、护甲和头盔；没有物品的敌人留下空盒，不会凭空补满装备。

靠近后在右侧「附近」栏点击对应敌人的战利品入口，打开独立灰色物资格子，点哪件拿哪件。电脑也可用 F 打开附近盒子；×、Esc 或再次按 F 关闭。打开盒子不会暂停对局，仍可移动，走出拾取范围自动关闭；暂停、打开地图/背包、上车、死亡和重开也会关闭。盒内条目不混入普通地面物品列表。

满容量时物品仍留在盒内并显示原因；部分拾取只扣实际拿走的数量；从盒中换枪时，换下的枪连同原弹匣放回同一个盒子。搜空后保留空箱并关闭绿色标记，换局时连同资源一起清理。重复死亡处理不会重复生成盒子，旧条目 ID 不能用于新盒子。盒子交互当前供玩家使用，机器人仍执行原有地面搜装逻辑。

验证：15 项盒子专用回归覆盖库存快照、重复死亡、所在楼层、单件与部分拾取、换枪回存、空盒、过期操作及资源释放；真实浏览器受控战斗击败敌人后，在 568×320、667×375、844×390、1024×768 下触摸开盒、拾取、重新打开和搜空均通过，同时验证了 Esc 关闭、走远关闭及返回菜单清理。测试没有替代手机真机或完整对局验收。

### 键鼠操作

| 键位 | 操作 |
| --- | --- |
| W A S D / 方向键 | 移动；跳伞时调整落点；驾驶时油门、倒车和转向 |
| 鼠标移动 | 转动视角 |
| 左键 / 右键 | 开火（未持枪时近战） / 按住瞄准 |
| Shift / Ctrl | 冲刺（载具加速） / 慢走 |
| 空格 | 跳跃；运输机上跳伞、空中开伞；驾驶时刹车 |
| C / Z | 蹲伏 / 趴下 |
| Q / E | 向左 / 向右侧身 |
| F | 拾取最近物资、上下车、跳伞、开伞 |
| 1 / 2 / 鼠标滚轮 | 切换主武器 |
| R / B | 换弹 / 自动枪切换自动与单发 |
| G | 投掷手榴弹 |
| 7 / 8 | 使用急救包 / 能量饮料 |
| M / Tab | 战术地图 / 背包，再按一次关闭 |
| V / H | 第一、第三人称切换 / 键位帮助 |
| Esc | 关闭浮层；无浮层时暂停 |

移动／开火会取消医疗动作，切换武器会取消换弹。打开地图／背包**不会暂停对局**，Esc 暂停才会冻结模拟。鼠标解锁、窗口失焦或切换标签页时自动暂停。

**触屏战术操作**：参考和平精英的键位布局原则（趴键放左手侧、探头键靠近开火键、为拖动视角留出空白）补齐了手机上原本缺失的三项：

- **趴下**：摇杆右侧的「趴下」按钮，点击切换趴下／起身。趴下后对移动需求低，可边开火边趴。
- **左右侧身**（探头）：开火键左侧的 ◄ ► 按钮，**按住生效、松手收回**，动作与键盘 `Q`／`E` 一致。
- **射击模式**：手机没有 `B` 键，改在暂停菜单的「射击模式」下拉里切换全自动／单发，仅对全自动武器生效。

矮横屏下的暂停菜单也压缩为两列，`390px` 高的屏幕不再溢出（原对话框高 509px，现 374px）。

**视角**：默认**第三人称越肩**，与和平精英一致。镜头拉到 3.3m、向右侧偏移 0.62，焦点压在胸口高度，使角色（含双腿与靴子）完整落在 HUD 上方，同时露出前方视野；开狙击镜时自动回到第一人称。按 `V` 或右上「视角」按钮切换，手机端与桌面共用同一开关。

角色现为具有 65 根骨骼、三个连续蒙皮网格的战术人物，肩、肘、膝与手指跟随真实权重变形；玩家、敌人和菜单共用同一造型资源，但骨骼、动作状态与骨纹理独立。支持待机、行走、奔跑、蹲伏、俯卧、空降、死亡与原有四种武器，物理高度、移动速度和第一人称武器规则未改变。

**竖屏提示**：触屏设备一旦竖屏就会**立即**看到全屏旋转提示（含手机旋转动画），并附一个「进入全屏横屏」按钮——点它进入全屏并尝试锁定横屏，多数安卓会因此自动翻转；iOS 不支持锁定，按提示手动横过来即可。以前遮罩只在开局后出现，导致竖屏下打开菜单毫无提示，容易被误认为是个竖屏游戏，已修正。

手机端：**横屏游玩**。竖屏时会提示旋转并自动暂停对局，旋转回横向后点「返回战场」继续。进入对局时尝试请求全屏并锁定横屏（iOS 及不支持该 API 的浏览器会静默失败，由竖屏提示兜底）。

左侧是**移动摇杆**：按住圆盘拖动即可八向移动，推杆幅度决定速度（轻推慢走、推满全速），松手自动回中并停止；拖动时旋钮跟手、圆盘高亮。右侧保留开火、瞄准、跳跃、蹲伏和换弹，下方使用道具及切枪。靠近地图上散落的物品时，右侧出现**「附近」拾取栏**：黄色紧凑条目、物品图标、名称／数量和简短说明，**点哪一件就拾取哪一件**。× 可收起，收起后可点「附近 ▾」重新展开；捡完或走远则全部隐藏，下次靠近物品重新显示。没有常驻「互动」键，上下车按钮只在可操作时出现。画面空白处或开火键上滑动可转动视角，摇杆与视角支持多指同时操作。

**锁定奔跑**：普通满推只移动，松手会刹停。要持续冲刺，需将摇杆**向上推过正常行程（至少 115%），保持约 0.6 秒**；侧推、倒退不会锁定。锁定后可松手继续跑，再点摇杆或回拉即可解除；点击物品条目拾取也会解除锁定并清掉自动奔跑惯性。蹲／趴、上车、空降阶段、暂停和重开均不保留锁定。

**移动与拾取（2026-10-28）**：无能量加成时，平地普通跑 4.4 m/s（15.8 km/h），冲刺 6 m/s（21.6 km/h）。保留上坡减速，不额外加速下坡；满速能转向、倒退，冲刺松手约 0.27 秒刹停。「附近」条目和实际拾取均要求水平距离小于 3.1m、垂直差小于 2.5m，点击时会重新校验；没有自动拾取。满容量的原因显示在对应条目，部分拾取会保留剩余数量。电脑 F 键仍可批量拾取附近物品。

**无中央文字横条**：已移除交互提示、空降文字面板、中央 toast 容器以及跳伞／落地教学横条；只保留必要的换弹、治疗进度。其他实际状态反馈留在左侧事件栏，与右侧拾取栏分开。

移动／拾取逻辑回归可执行 `npm test`（直接运行真实模块方法，不需要浏览器或测试框架）。

**跳伞**：手机上提示「F / 空格」是没法按的，所以运输机阶段右侧会出现一个醒目的**「跳伞」按钮**（金色，带呼吸光效），点它离开运输机；进入自由落体后同一位置变成**「开伞」按钮**，点它提前开伞，不点则低空自动开伞。开伞后按钮自动隐藏，战斗键恢复。这个按钮只在空中出现，因此不参与自定义布局。参考了和平精英的做法：离机与开伞各有一个专属按钮，放在右手拇指的自然落点。

触屏按键可以自定义：暂停菜单 →「按键布局」，拖动按键（含移动摇杆）调整位置，用下拉框选中某个控件后拖动滑杆调整大小，可「保存」「恢复默认」或「取消」。保存后写入 `localStorage`（键名 `peace_elite_touch_layout_v1`），刷新与换局后保持；选择「恢复默认」并保存会清除该记录，回到 CSS 原生的响应式布局。

## 手机端体验调整（2026-10-28，浏览器模拟验收通过）

本轮完成以下改进，并重新构建单文件试玩版本；真机触感和持续帧率仍需在设备上确认：

- 开火键支持按住滑动跟枪；移动、观察和开火可多指同时操作，视角触点释放后可无跳变交接。

## 实现边界

这是可完成一局的浏览器单机游戏，不是商业《和平精英》客户端：场景为低多边形原创缩尺海岛，没有真人联机、组队／救援、完整配件树、官方全部枪械／地图、游泳系统或复杂车辆损毁系统。深水会造成伤害，载具不能在水中行驶。AI 使用视线感知、真实射线交火、资源搜索、局部避障和缩圈转移，并非多人联网玩家。

高／低画质控制屏幕像素比与实时阴影，不会中途改变物理地图。游戏状态仅保存在内存，刷新会结束当前对局。页面无登录、无统计上报、无外部网络请求。

触屏自定义布局与横屏引导本轮新增，并在无头 Chrome（触屏模拟、844×390 横屏 / 390×844 竖屏）下按打包产物验收：

- 横屏对局：13 个触控控件（移动摇杆 + 12 个按键）均有真实尺寸，可从暂停菜单进入布局编辑，拖动改位置、滑杆改大小、保存写入 `localStorage`，刷新并重新开局后位置与缩放保持。
- 移动摇杆：拖动改变玩家坐标，松手回中停止，死区内不移动；推杆幅度决定速度（实测轻推 8 km/h、推满 43 km/h）；摇杆与视角可多指同时操作；驾驶时摇杆控制油门与转向。
- 「恢复默认」+ 保存会清除存储记录，控件回到 CSS 响应式布局；朝向切换后自定义位置不漂移；对局中与编辑中的控件坐标逐项一致。
- 竖屏：菜单仍可读可点；对局中自动暂停并显示旋转提示遮罩；竖屏点「开始行动」「返回战场」均被拦截并给出提示，转回横屏后可正常继续。
- 容错：`localStorage` 内容损坏或数值越界时忽略该记录，不阻塞启动。
- 桌面端（无触屏）：不显示摇杆与布局入口，`.touch-controls` 保持隐藏，键盘移动正常。
