# 和平精英 · 海岛行动

与 `pelican-bike`、`cf-transport-ship`、`qq-speed` 并列的独立 Three.js 网页游戏。
这是**原创程序化海岛、离线单机战术竞技致敬作品**，不是官方游戏或官方海岛的等比例复刻，不包含官方模型、图片、音频、商标图形或联网服务。

## 本地构建与运行

与其他三个游戏采用相同方式：使用 esbuild 将源码、样式和 Three.js 内联成单个 HTML，**不需要开发服务器**。构建工具要求 Node.js 18 或更新版本；浏览器需要 WebGL2，推荐 Chrome / Edge。

```sh
cd peace-elite
npm install
node build.mjs
```

然后直接用浏览器打开 **`dist/index.html`**，也可将该文件放到任意静态托管服务。不要直接打开 `src/index.html`，它是用于注入代码和样式的源码模板。

构建产物不依赖 `/src` 路由、import map、外部 CDN 或后端；首次开始游戏时按浏览器规则启用声音与鼠标锁定。`dist/` 与其他项目一样不提交到 Git。

本轮仅调整源码和构建约定，尚未执行构建或部署。
## 玩法

- **48 人单人生存赛**：1 名玩家与 47 名本地机器人。运输机进场，主动离机／到航线末端自动跳伞，自由落体、主动／低空自动开伞，落地开始搜装。
- **1.4 × 1.4 km 地图范围**：9 个原创地点，中央集镇、海岸与港区、农田、仓库、树林、山地、道路、双桥河道；31 栋可进入建筑，门洞、屋顶与地形参与碰撞和射线遮挡。
- **真实资源状态**：地图 138 个物资生成点（其中 93 个室内），按种类生成枪械、弹药与装备；机器人也需要实际搜集武器，不会凭空得到满装装备。
- **四种枪械**：M416、AKM、UMP45、Kar98k；双武器位、相应口径弹药、换弹时间、散布与后坐、瞄准和狙击放大、头部／身体伤害、头盔／防弹衣减伤。UMP45 在本作使用简化的 9mm 弹药配置，并非官方参数表。
- **医疗与战术**：急救包、持续恢复的能量饮料、可反弹且有遮挡判定的破片手榴弹、蹲伏、趴下、侧身和第一／第三人称切换。
- **转移与决胜**：五辆越野车，油门、倒车、转向与刹车；七阶段、约 10 分钟的收圈，圈外持续失去生命，最后一名存活者获胜。死亡不复活，结束后可以重新开局。
- **完整界面**：主菜单、实时罗盘／小地图、全屏战术地图、背包、键位帮助、暂停、击杀播报、胜败与排名结算；手机屏幕提供移动、视角拖动及主要操作按钮。
- **程序化表现**：角色／降落伞／枪械／载具／地形模型，枪声、脚步、换弹、命中、引擎、风声和提示音均由代码生成。

### 键鼠操作

| 键位 | 操作 |
| --- | --- |
| W A S D / 方向键 | 移动；跳伞时调整落点；驾驶时油门、倒车和转向 |
| 鼠标移动 | 转动视角 |
| 左键 / 右键 | 开火（未持枪时近战） / 按住瞄准 |
| Shift / Ctrl | 冲刺（载具加速） / 慢走 |
| 空格 | 跳跃；运输机上跳伞、空中开伞；驾驶时刹车 |
| C / Z | 蹲伏 / 趴下 |
| Q / E | 向左 / 向右侧身 |
| F | 拾取最近物资、上下车、跳伞、开伞 |
| 1 / 2 / 鼠标滚轮 | 切换主武器 |
| R / B | 换弹 / 自动枪切换自动与单发 |
| G | 投掷手榴弹 |
| 7 / 8 | 使用急救包 / 能量饮料 |
| M / Tab | 战术地图 / 背包，再按一次关闭 |
| V / H | 第一、第三人称切换 / 键位帮助 |
| Esc | 关闭浮层；无浮层时暂停 |

移动／开火会取消医疗动作，切换武器会取消换弹。打开地图／背包**不会暂停对局**，Esc 暂停才会冻结模拟。鼠标解锁、窗口失焦或切换标签页时自动暂停。

手机端：左侧方向键移动，拖动画面看向，右侧开火、瞄准、跳跃、交互、蹲伏和换弹；下方使用道具及切枪。瞄准按钮为开关式；横屏体验更合适。

## 实现边界

这是可完成一局的浏览器单机游戏，不是商业《和平精英》客户端：场景为低多边形原创缩尺海岛，没有真人联机、组队／救援、完整配件树、官方全部枪械／地图、游泳系统或复杂车辆损毁系统。深水会造成伤害，载具不能在水中行驶。AI 使用视线感知、真实射线交火、资源搜索、局部避障和缩圈转移，并非多人联网玩家。

高／低画质控制屏幕像素比与实时阴影，不会中途改变物理地图。游戏状态仅保存在内存，刷新会结束当前对局。页面无登录、无统计上报、无外部网络请求。

## 结构

```text
peace-elite/
  src/
    main.js       页面启动与明确错误展示
    game.js       对局生命周期、玩家／AI、战斗、拾取、载具与表现整合
    input.js      键鼠、指针锁定、触控、输入边沿
    rules.js      武器、背包、伤害与缩圈的唯一规则来源（纯函数）
    physics.js    空间索引、水平／垂直碰撞、地形与角色射线
    terrain.js    纯函数地形与道路高度、地点定义
    world.js      程序化地图、建筑、树林、水面及资源释放
    models.js     角色、武器、拾取物、越野车与飞机
    audio.js      Web Audio 合成音效
    hud.js        界面更新、地图绘制与菜单动作
    index.html    页面模板
    style.css     响应式游戏界面
  build.mjs       与其他三个游戏一致的单 HTML 打包脚本
  check.mjs       JS 语法与相对模块导入检查
```
